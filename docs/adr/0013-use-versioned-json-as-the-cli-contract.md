# ADR-0013：CLI 以版本化 JSON 作为稳定输出契约

内置 CLI 的标准输出只承载带有明确模式版本的 JSON 结果，日志与诊断信息写入标准错误；只要 CLI 成功形成符合契约的 JSON，进程即以零退出码结束，研究结果的已支撑、受限或已阻断状态只由 JSON 字段表达，非零退出码仅表示参数、协议、I/O 或内部执行错误。`SKILL.md` 负责指导 Agent 将结构化结果解释为面向研究者的简报。首版不承诺 Markdown 或自然语言输出格式为稳定接口，以避免展示逻辑与研究事实、证据和状态的机器可读契约耦合，并让任何能够运行 Python 与解析 JSON 的 Agent 都能一致地调用该 Skill。
