# 按研究能力声明锁定的可选依赖

完整 A 股研究需要通达信协议、数据表处理和特定来源客户端，不能继续把“只使用 Python 标准库”作为所有能力的永久约束。Skill 保持自包含安装产物和标准库可运行的可信内核，但允许单项研究能力声明版本锁定、按需安装的可选依赖；缺少依赖时返回明确的能力不可用结果，不得静默切换口径或伪造空数据。凭据型能力同样按 Adapter 单独声明环境变量，不进入命令参数、日志或结果。

可选依赖属于内部 Adapter 的 Implementation，不进入 `research(request) -> research result` 外部 Interface。能用标准库可靠实现的 HTTP 与确定性计算继续使用标准库；只有确实提供不可替代协议或行为的依赖才能进入能力声明。我们接受安装不再对所有功能保持零依赖，以恢复真实用户价值，同时保留最小内核的可移植性和失败关闭行为。
