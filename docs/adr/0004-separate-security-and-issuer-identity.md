# 分离证券与发行主体并拒绝身份猜测

研究标的由研究时点上的唯一证券及其关联发行主体构成。证券使用交易所、证券代码、证券类型和有效期间识别，用户提供的名称或代码只作为标的线索；身份解析存在歧义、类型不符或市场冲突时必须停止并请求澄清。我们接受额外的解析步骤和失败情况，以防证券级数据与发行主体级数据错配。

交易所归属必须由对应交易所的证券名录观测确定，不能从代码前缀或巨潮 `orgId` 格式推断。巨潮证券字典可以在未声明交易所时按相同证券代码与简称参与独立交叉核验；如果它明确声明了不同交易所，则仍按来源冲突阻断。`orgId` 无法证明证券与发行主体关系时，候选证券可以保持受限，但该关系必须标为未验证，不能把证券身份核验扩大解释成发行主体身份核验。
