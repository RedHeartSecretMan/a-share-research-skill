# 完整 A 股研究技能 v0.1.0

## 目标

v0.1.0 必须让研究者通过自然语言完成已经确认的全部使用场景，并可选择版本化预置研究方案，同时把每个结果纳入本项目的身份、时间、来源、口径、冲突和失败关闭契约。端点返回数据只表示取得观测，不自动表示事实达到已支撑。

v0.0.1 的子命令式 CLI 只属于可信证据内核的实现历史，不构成 v0.1.0 外部 Interface。v0.1.0 的调用者直接使用版本化 `ResearchTask`。

## 外部 Interface

遵循 ADR-0007，调用者和测试只依赖一个深 Module Interface：

```text
research(request) -> research result
```

CLI 使用一个公共入口承载该 Interface：

```text
<python> scripts/entrypoint.py run --request <research-task.json>
```

`ResearchTask` 至少包含：

- `schema_version`：请求契约版本；
- `task_type`：稳定的研究任务类型，不是供应商端点名；
- `subjects`：一个或多个已经解析或待解析的标的线索；
- `as_of`：北京时间显式研究日期；
- `window`：交易日数量、报告时间窗或事件时间窗；
- `parameters`：该任务特有且版本化的参数；
- `source_policy`：是否允许实验来源、凭据型增强和降级来源。

`ResearchResult` 至少包含：

- `schema_version`、`task_type` 和规范证券身份；
- `status`：`supported`、`limited` 或 `blocked`；
- 用户请求的事实、序列、指标或材料；
- 每个结果的证据 ID、来源角色、来源操作、口径和时间；
- 冲突、拒绝观测、来源错误、降级路径和限制；
- 确定性计算的公式、操作数和谱系；
- 对用户原始研究问题的直接回答，不把较窄结果冒充完整答案。

`run --request <research-task.json>` 是唯一受支持的公共调用形式。v0.1.0 不承诺旧子命令兼容，也不按来源端点逐个暴露浅 Interface；身份、行情、估值和证据处理均由 `ResearchTask` 路由到深 Module 内部实现。

## 内部 Module 与 seams

```text
ResearchRuntime
├── Identity Module
├── Market Series Module
├── Valuation Module
├── Research Content Module
├── Capital And Event Module
├── Market Signal Module
├── Derivatives Module
└── Workflow Module
    └── internal SourceOperation seams
        ├── production source Adapter
        ├── independent fallback Adapter
        └── fixed-response test Adapter
```

- `ResearchRuntime` 负责路由、研究边界、状态和最终结果；
- 各研究 Module 隐藏供应商差异、降级、字段映射和计算；
- 只有真实变化的外部来源设置内部 seam；生产和固定响应测试至少形成两个 Adapter；
- 测试通过研究 Module 或 `ResearchRuntime` 的 Interface 断言可见行为，不把上游函数实现复制成新的公共测试面；
- 上游代码用于迁移行为和来源知识，不原样复制成一个巨型 `SKILL.md`。

## v0.1.0 能力矩阵

### 行情与估值

| 用户场景 | v0.1.0 任务结果 |
| --- | --- |
| 个股估值 | 实时/最近完成价、当前与前向 PE、PB、PEG、PE 消化时间及计算口径 |
| 最近 N 日走势 | 规范 OHLCV 序列、复权与公司行动说明、累计涨跌、最大回撤、波动和量价变化 |
| ETF 行情 | ETF 身份、价格、涨跌、成交与对应时间 |
| 批量对比 | 多标的同口径估值和证据缺口横向表 |

自动当前估值把已确认身份、交叉核验价格、有效总股本、适用财务报表和前向一致预期视为该任务明确请求的关键输入。任一关键输入的唯一来源不可用且没有合格独立降级时，单票结果必须为 `blocked`，但仍须保留已经取得的证据、可计算指标和其他指标的 `not_calculable` 状态。分母非正等输入完整后的“无估值意义”，以及不替代项目计算的供应商交叉差异，不单独触发阻断。

批量对比必须保留每个请求标的及其逐行状态。部分标的阻断而仍有可比较标的时，整体为 `limited` 并显式列出阻断标的；所有标的均阻断时，整体为 `blocked`。不得筛除阻断行后把剩余结果描述成完整比较。

## 预置研究方案

`research_workflow` 提供四个固定、版本化的请求方案。它们服务于常见研究问题，但不构成新的数据能力，也不允许调用者提交任意步骤或依赖图：

1. **单票估值方案**：身份 → 价格 → 一致预期 EPS → 前向 PE / PEG / PE 消化时间 → 限制；
2. **批量对比方案**：统一研究时点与口径 → 多标的估值 → 缺失与异常 → 横向排列；
3. **主题研报方案**：多关键词检索 → 个股/行业研报 → PDF 定位 → 重复和来源交叉；
4. **新标的研究方案**：身份 → 机构覆盖 → 估值 → 概念板块 → 资金流 → 龙虎榜 → 解禁 → 两融 → 研究缺口。

## 来源与依赖政策

- 免费公开来源构成可运行基线，凭据或付费来源只能是显式增强；
- `iwencai` 等凭据能力只读取文档指定的环境变量，缺少凭据时报告该能力不可用；
- 通达信等非 HTTP 协议可以使用版本锁定的可选依赖，遵循 ADR-0016；
- 东财等有频率风控的来源必须串行限流、复用会话并保留退避和降级诊断；
- 来源响应为空、证券不符、字段变化、陈旧报价或权限拒绝都必须显式失败，不得解释为“没有数据”；
- 不同来源只有在证券、时间、单位和口径一致时才能交叉核验。

## 纵向交付切片

1. **市场序列**：身份、实时/完成行情、N 日 OHLCV、ETF、走势计算；
2. **估值财务**：股本、财务三表、季度快照、一致预期和估值公式；
3. **研究内容**：研报、PDF、新闻、公告、F10、互动易；
4. **资金事件**：资金流、北向、龙虎榜、解禁、两融、大宗、股东户数、分红；
5. **市场信号**：题材、概念、行业、涨停、监控、异动、热度；
6. **ETF 期权**：合约、报价、希腊字母和 IV；
7. **预置方案**：为常见问题固化已有任务的编排、批量语义和最终研究简报。

市场序列是其他切片的前置。估值财务、研究内容、资金事件和市场信号在共同 Interface 稳定后可以并行；预置方案依赖相关底层切片完成。

## 发布门槛

v0.1.0 只有在以下条件全部满足时才能发布：

- 能力矩阵中的每个用户场景至少有一个确定性任务契约；
- 每个来源操作有固定最小响应的离线测试、身份/时点/口径失败测试和显式来源状态；
- 每个用户场景至少完成一个真实联网 smoke test，并记录日期与环境限制；
- 主来源有适用的独立降级，或明确说明没有可接受降级并返回 `blocked`；
- 四个预置方案通过公开 `ResearchRuntime` Interface 的 E2E 测试；
- 蓝色光标案例完成最近 10 日走势、资金/题材/公告交叉解释；
- 工业富联案例完成新标的预置方案和证据缺口说明；
- 全量测试、静态检查、Skill 标准校验和远程标签干净安装通过；
- README 的使用示例与实际可调用能力逐项一致；
- Release 不把实验来源结果描述成已独立核验的事实。
