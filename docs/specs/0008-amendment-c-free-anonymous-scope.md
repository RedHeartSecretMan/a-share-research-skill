# Spec 0008 Amendment C：免费匿名来源下的 0.4.0 交付范围

> 后续公开能力范围以 [Amendment D](0008-amendment-d-qualified-public-scope.md) 为准；本修订的其余退出范围和质量要求继续有效。

## 授权与优先级

维护者于 2026-10-16 明确授权：“如果在当前‘免费、匿名访问’的边界内遇到无法实现的功能需求，可以放弃实现这个功能，继续推进项目直到 0.4.0 完成”。本修订落实该授权，优先于 Spec 0008、Amendment B 及 Tracker 中与下文冲突的范围、依赖和验收条款；未冲突的质量、证据与安全契约继续有效。范围调整不等于实现验收，不把未接受候选改记为 Accepted。

本次只使用免费匿名来源；不购买、不注册账号、不检查凭据、不调用账号 API。既有授权允许继续必要的有界匿名验证和将已验收检查点快进同步到 `origin/codex/v0.4.0-dag`。不增加默认分支、标签或 GitHub Release 的写入授权。v0.3.0 的历史发布和标签保持原样。

## 保留的交付与公开行为

发布 `market_overview_research@2.0`：保留现有十项能力，接入 `market_trading_session`、`major_broad_indices`、`whole_market_turnover`、`whole_market_margin` 四项已实现基础能力。固定清单仍为十五项；上述十四项依据层级和适用性产生义务，第十五项 `market_wide_intraday` 明确为 unsupported，无 operation obligation、观测、计算或 coverage。

- `fast` 只执行 core；`standard` 执行 core 加 standard；deep 仍须显式请求。显式请求盘中槽位应得到稳定的 unsupported 原因，不调用其来源，也不伪装成 outside-session skip 或数据故障。
- 公共市场工作流切换到 `@2.0`，不保留 `market_overview_research@1.0` 运行时兼容。其他已发布工作流保持原版本与语义。
- 不对外暴露未实现的筛选入口；筛选请求在任何来源调用或 artifact 写入前明确拒绝。结果信封 `schema_version: "1.0"` 与唯一 `run --request` 公共入口保持不变。
- 已接受的 Universe、身份来源、provider lane、immutable evidence、prepared values 和 Result Artifact 模块保留其内部契约、测试和已有验收证据；存在模块不等于存在公共筛选产品。不为使用这些模块而新增公共命令。
- 三所市场口径、四个固定指数身份、真实时点、字段完整性、缺失/失败隔离和谱系继续严格执行。部分失败不能生成完整全市场结论。

## 验收影响与最终完成条件

历史 Accepted 记录、原始测试身份和完整 review 保持不变。定义检查点只调整责任，不接受五张退出票的候选；确认其 writer 已停止并保留工作区后关闭 claim。#96/#97/#98 使用本次新检查点作为之后的 Ticket Base，按普通实现、审查和串行集成规则交付。

最终完成以本修订的十六张有效票和实际发布能力为分母。所有有效票须 Accepted，无活动 claim 或待同步 transition，最终代码、文档、安装、定义和实际 operation 清单一致，保留能力的最终证据合格，且本地集成点与远端分支回读相等。退出功能应列为本版未提供，不计为通过、成功调用或完成的测试。

若后续最终验证证明另一保留功能也无法在免费匿名边界实现，维护者已授权同类范围退出；协调者须先保存具体失败/不可用证据，更新其公开入口、消费者、文档、分母和最终门禁，经新的 Definition Checkpoint 后继续。普通代码缺陷、可修复测试失败或暂时网络故障仍需修复，不能借此删除功能或跳过质量门禁。
