# Spec 0004：A 股研究 v0.1.1 呈现与发布修订

## 状态

已接受，目标版本为 v0.1.1。

## 背景

v0.1.0 已交付 Spec 0003 定义的研究内核和能力矩阵。首次发布后的文档终审发现，安装版本、F10 术语、跨平台 Python 选择、研究判断边界和安装产物的信息层级仍需收敛；这些问题不要求改变 CLI、任务 schema、计算方法或来源资格。

## 范围

v0.1.1 是兼容的文档与 Agent 呈现修订：

- 保留 v0.1.0 的公共 CLI、任务类型、JSON 契约和来源行为；
- 将 `SKILL.md` 收敛为研究步骤、路由和核心守则，把命令与分支细节放入按需引用；
- 以 `references/analysis-boundary.md` 作为研究判断、条件触发位、署名观点和投资行动建议的唯一执行规范；
- 在领域词汇中区分事实主张、推断、研究判断、研究建议、条件触发位和投资行动建议；
- README 解释 Spec 0001–0004 的关系、F10 的含义、`mootdx` 的可选依赖角色，以及 Windows、macOS、Linux 的 Python 3.12 选择；
- 案例展示 `limited` 结果仍可形成有证据、有条件的 Agent 研究判断，同时保持事实、计算、署名观点和推断分离。

## 呈现行为

Agent 按问题和整体状态选择呈现分支：

1. 身份核对、证据包校验等直接证据问题，只回答请求的证据，不附加无关判断；
2. 整体 `blocked` 时，说明阻断缺口和继续研究所需证据，不形成研究判断或条件触发位；
3. 其他需要解释的 `supported` 或 `limited` 结果，在证据之后形成有基准、有假设、有周期且标注为 Agent 推断的研究判断；
4. 可复算的价格或指标条件可以作为重新研究的条件触发位，不能表达为执行指令；
5. 外部评级、目标价和买卖观点只按署名观点呈现；项目或 Agent 不生成自身评级、目标价、直接买卖/持有、仓位或自动交易指令。

上述执行规则只在安装产物的 `references/analysis-boundary.md` 定义；README 和本 Spec 只说明产品意图与验收范围。

## 依赖边界

核心运行时继续只依赖 Python 3.12+ 标准库。F10 是已集成的研究内容类型，但其来源 Adapter 需要版本锁定的 `mootdx==0.11.7`；因此它保持按需安装，缺少依赖只阻断明确请求 F10 的步骤，不扩大默认安装面，也不影响其他能力。

## 发布门槛

v0.1.1 只有在以下条件全部满足时才能发布：

- README 中英文版安装命令固定到 `v0.1.1`，不移动或重写 `v0.1.0` 标签；
- `SKILL.md` 直接链接 CLI、证据、估值和分析边界引用，入口正文少于 1500 个空白分隔词；
- UI 默认提示只在问题需要解释且结果未阻断时请求 Agent 研究判断；
- 蓝色光标和工业富联案例均展示 Agent 研究判断、风险、失效条件和可复算条件触发位，且 Markdown 首个非空行是一级标题；
- 前向测试覆盖身份直答、整体阻断、可解释非阻断三类分支；
- 全量离线测试、Ruff、strict mypy、Skill 校验和 `git diff --check` 通过；
- 单独形成 v0.1.1 发布审计，历史 v0.1.0 审计不被改写成新候选结果；
- 远程 `v0.1.1` 标签干净安装和 GitHub Release 在发布动作发生后另行回读确认。
