# 首版规格：当前估值证据简报

状态：已被 [首个可构建规格：可信 A 股研究 Skill 基础能力](0002-trustworthy-a-share-research-foundation.md)取代。本文保留为早期自动估值方案记录，不再作为实现依据。

## 目标

为自主研究者生成一只身份明确的 A 股证券的当前估值证据简报。简报提供可复算、可追溯且明确披露限制的研究材料，不判断证券便宜或昂贵，不提供买卖建议。

首版只回答以下三个指标：

- 总市值
- PE TTM
- PB MRQ

供应商直接提供的 PE、PB 只能用于交叉核验，不能替代本项目的计算与证据链。

## 交付与运行环境

- 仓库唯一安装产物位于 `skill/a-share-research/`。
- Skill 内含平台中立的 `SKILL.md` 和模块化 Python CLI。
- 用户运行时要求 Python 3.12 或更高版本，不依赖第三方 Python 包。
- 支持能够加载 `SKILL.md`、运行 Python 和访问网络的 Agent；不绑定 Codex、Claude Code 或某个操作系统。
- 开发工具可以作为锁定的可选依赖，但不得成为 Skill 的运行依赖。

## CLI 边界

CLI 使用一个入口脚本和固定子命令。首版规划以下命令：

- `resolve`：将代码、简称或名称等标的线索解析为候选证券。
- `valuation`：只接受完成身份解析后的规范证券标识和明确研究日期。

示例接口：

```text
python skill/a-share-research/scripts/a_share_research.py \
  valuation --security SSE:600519 --as-of 2026-08-01
```

CLI 不接收或解释自然语言，也不调用模型。模型负责理解用户问题，`SKILL.md` 负责选择能力和解释结果，CLI 负责确定性的数据获取、校验与计算。

## 请求约束

- `valuation` 必须收到交易所限定的规范证券标识，例如 `SSE:600519`。
- 裸代码、证券简称或公司名称只能作为 `resolve` 的标的线索。
- 身份存在歧义、证券类型不符或市场冲突时不得猜测，研究必须阻断并请求澄清。
- 所有研究请求必须收到 `--as-of YYYY-MM-DD`。
- 用户所说的“当前”由 Agent 按北京时间解析为具体日期后再调用 CLI。
- 历史日期以该日结束为信息边界；当天研究同时受实际获取时间约束，不得使用尚未完成或尚未正式形成的当日收盘数据。

## 估值口径

- 使用研究时点前最近一个已完成交易日的未复权收盘价。
- 当天收盘后，只有来源明确表明数据为正式日线收盘数据时，才能使用当天价格。
- 价格证据必须包含交易日、币种、价格类型和交易状态。
- 总市值使用研究时点已经生效的普通股总股本，不使用流通股本代替。
- TTM 归母净利润使用上一完整会计年度加本年最新累计期、再减上年同期累计期。
- MRQ 归母净资产使用最新已公开定期报告合并口径的归属于母公司股东权益。
- 财务预测不得替代定期报告数据。
- PE 或 PB 的分母小于或等于零时，指标状态为“无估值意义”；输入缺失或口径不兼容时为“不可计算”。
- 首版不计算 A/H、A/B 等多类别或多市场发行主体的发行主体整体估值。

## 结果契约

- `stdout` 只输出带明确模式版本的 JSON；日志与诊断写入 `stderr`。
- 只要形成符合契约的 JSON，进程退出码为 `0`，领域状态只由 JSON 字段表达。
- 非零退出码仅表示参数、协议、I/O 或内部执行错误。
- 需要精确复算的数值使用十进制字符串并显式携带单位；计算使用 `Decimal`，不得以二进制浮点数进入证据链。
- JSON 必须包含请求、研究标的、研究与获取时间、简报状态、逐项指标、事实主张、证据项、计算过程、冲突和限制。
- 每项证据记录来源角色、来源定位、原始规范化值、单位、口径、证据时点、公开时点和获取时间。
- 默认运行无状态，不创建隐式数据库、缓存或用户配置；`--output` 可以显式保存与标准输出相同的 JSON。

## 状态汇总

- 每个指标独立标记为“已支撑”、“无估值意义”或“不可计算”。
- 三项指标均形成有效结果时，整体简报为“已支撑”；“无估值意义”属于有效结果。
- 至少一项可可靠回答、其他指标不可计算时，整体为“受限”。
- 身份或共同估值价格无法确认，或者三项指标全部不可计算时，整体为“已阻断”。

## 凭据与隐私

- 凭据只从明确命名的环境变量读取。
- 不允许通过命令行参数传入凭据。
- Skill 不创建或修改全局凭据配置。
- 日志、JSON、缓存和测试夹具不得包含凭据。
- 缺少可选凭据时返回结构化限制原因，并继续尝试无需该凭据的合格来源。

## 数据源准入门槛

首版核心能力必须存在无需购买订阅、积分或单独数据权限的完整路径；免费注册凭据可以属于免费基线。每个 Adapter 操作独立接受资格审查，不能按腾讯、东方财富、同花顺等提供方品牌整体通过或淘汰。

候选操作只有满足以下条件后才能成为正式证据来源：

- 已验证证券身份与市场路由。
- 已验证字段、单位、复权、交易状态和时间语义。
- 能确定信息在研究时点是否已经公开。
- 能把空结果、限流、反爬、协议漂移和上游异常显式化，不会静默返回错误证券或错误口径。
- 来源条款允许本项目的访问与必要使用。
- 至少以代表性 SSE、SZSE 证券和关键失败案例完成交叉核验；BSE 在首轮原型中探测，通过同一门槛后才能进入首版支持范围。

未通过门槛的免费直连接口可以保留为实验、诊断或交叉核验候选，但不能单独支持事实主张。若免费组合无法通过门槛，应重新评估依赖或覆盖范围，不得降低可信度标准。

## 验证策略

- 默认测试完全离线，使用脱敏、最小化且来源明确的固定响应夹具。
- 实时数据源探测单独运行，不混入普通单元测试，也不自动改写夹具。
- 测试预期值使用独立的已知事实或人工演算结果，不能重复实现同一算法来生成预期值。
- Python 3.12 是最低兼容版本；本机更高版本通过不代表最低版本已经验证。

### 待确认的测试 Seam

1. **CLI 进程 Seam**：从命令参数到 `stdout`、`stderr` 和退出码的完整可观察行为。

3. **Adapter 操作 Seam**：对外部系统的每个合格操作使用固定响应夹具验证其领域语义；实时探测不属于离线测试。

- Skill 骨架符合命名、元数据和目录校验规则。
