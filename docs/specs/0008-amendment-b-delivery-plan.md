# Spec 0008 Amendment B：补齐生产链路与恢复契约

## 状态与适用范围

**本地修订提案，尚未应用到 GitHub Tracker 或生效 DAG。**

本提案基于 `b564f9e3c64477d3c95277cfb9ebb2f58f278a23` 的 [Spec 0008](0008-v0.4.0-market-foundation-and-screening.md) 和 [现行定义快照](../../.dag/definition-github-spec-0008.json)。维护者已同意开始计划修订；本文把已确认的责任缺口与需要选择的产品、故障模型和来源探索政策分开列出。提案不接受任何历史候选，不启动实施，也不改变现行定义索引。

v0.3.0 仍是当前稳定版本。单一公共 `run --request`、统一结果信封、三交易所分母、四因子公式、缺失不补值或重加权、原始排名不被候选失败改写等要求保持不变。本文生效后只按明确列出的条款修订 Spec 0008；其余义务继续有效。

## 需要确认的三项决定

| ID | 推荐方案 | 对现有计划的影响 | 当前状态 |
| --- | --- | --- | --- |

## 修订内容

1. 增加真实三交易所时点化名单和身份获取的交付责任，保留 #110 已验收的快照与对账模块。
2. 为盘中累计成交额和证券去重广度定义独立正式 owners；#112 的日报成交额与两融不被重解释成盘中观测。
3. #117 同时交付筛选所需的冻结研究上下文；#120 和 #69 消费该上下文，恢复时复用原研究边界。
4. #69 明确候选参数、发行主体范围、BSE 和历史研究的映射与失败行为。
5. #108 以明确状态、提交点、所有权和故障矩阵收敛恢复协议，继续消费 #115 的 prepared values。
6. 在现有有限请求预算之外补容量证据，并区分 expected、eligible、ranked 与来源失败，明确最终发布的可用 owner 门禁。

## 生效与交付顺序

1. 完成 B1–B3 的明确决定和本提案审查。需要改变产品范围、故障保证或验收门禁时，在对应决定中逐项记录。
2. 在获得 Tracker 写入授权后，以现行任务完整正文为基础应用职责和 AC 差异；新增任务使用真实返回的 Issue ID，回读父子关系与原生依赖。不得从逻辑 ID 猜测 Issue 编号。
3. 保留现行 Accepted、Superseded 与未接受候选的历史身份；对受影响的活动任务先确认现有 writer 已停止，再交接新定义。历史关闭不自动等于新义务验收。
4. 从回读后的完整正式正文形成新的 definition-only 快照，把本文和配套规范纳入 `.dag/definition-index.json`，更新所有选中文件的真实 blob OID。快照保留完整定义，不只保存摘要或链接；不加入 claim、workspace、Agent、运行回执或临时验收状态。
5. 在隔离分支形成候选，验证精确提交的定义索引、图无环、义务覆盖、文档与独立 Standards／Spec 审查。现行集成线只在其既有发布授权和串行集成协议下接受该 Definition Checkpoint；本地提案提交不等于已完成 checkpoint。
6. 生效后按新图执行。先验证来源假设和小型组合案例，再打通筛选 `fast` 的 create／partial／resume／finalize，之后接入 `standard` 候选研究。市场链独立形成完整纵向切片；#97 复验整体分发，#98 只使用最终同候选证据。

## 接受影响

- #101 的已发布 workflow 校验和封闭输入原则保留。B1 带来的未发布筛选形状差异由 #69 实现并回归，不把旧 shape 的验收记录冒充新 shape 的验证。
- #105／#114 的 operation 资格、字段去向和精确归一化成果保留；新增 owners 必须新增自己的资格，不借用日报合同。
- #110 的确定性证券池对账和输入快照成果保留。真实来源获取、共同完成日推导和跨日恢复是明确分配给新增或下游任务的义务。
- #115 与 Maintainer Decision A 保留。生命周期不得重新扫描调用者对象，也不得把已排除的任意解释器反射攻击重新引入验收。
- #108 保留原身份及已有未接受候选作为参考；修订其协议不能将历史候选自动接受，也不因修复次数机械替换任务。
- 原 Spec 的所有未修改义务和最终整体验证仍有效。新增能力或定义差异需取得自己的最终验证证据。

## 本提案的审查标准

- 每项新增生产输入有明确 owner、消费者和独立验收输出；每条 hard edge 对应真实的输出消费。
- 源数据成功、规范化可采纳、完整分母、数学可复算和发布完成分别有证据，互不替代。
- 同日、跨收盘和跨日恢复不会扩大原 cutoff；获取时间仍为真实时间。
- 无日报冒充盘中、板块计数冒充证券去重广度、当前名单反推历史、缺输入自动填值或候选失败改写排名。
- 没有依靠测试替身推断真实来源或真实文件系统可用；没有改变现行发布物或秘密放宽既定门禁。
- 未选定的设计方案不进入正式 Tracker、定义索引或执行调度。
