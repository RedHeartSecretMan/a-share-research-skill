# Spec 0008 Amendment D：日报来源条件下的公开范围调整

## 授权与优先级

维护者于 2026-10-16 已授权：免费、匿名访问下无法实现的功能可以放弃，继续推进 0.4.0。本修订落实该授权，对下文明确列出的公开范围、依赖与最终证明责任优先于 Amendment C 及更早规范；其余来源真实性、时点、单位、权限、安装、审查和质量要求继续有效。它不改变 `run --request` 或 `schema_version: "1.0"`，不增加费用、账户或发布权限。

## 来源证据与本版退出范围

现有免费匿名日报路线的限制来自来源契约：六个默认成交额／两融 owner 均保留未证明的发布时间；SSE 成交额纯 A 股／CDR 排除口径未证明，SZSE 对应统计包含 CDR；SSE 两融数量的股、份、手也不能直接当作统一股票股数。此前 H/I/L/N/Q 来源核查与当前生产路径均未取得所需证明。原模块据此保留 unadopted/unknown，不生成合格观测或全市场合计。这不能靠填入获取时间、报告日期、零值或宽松别名修复，也不表示全球不存在其他合格免费来源。

据此，`whole_market_turnover`、`whole_market_margin` 移出本版公开可执行能力。保留已有内部 Market Foundation 报告解析、字段资格、精确归一化、局部失败及 provider lane 契约；不再把这些内部模块的存在称为两项公开能力已可用。

## 公开工作流

`market_overview_research@2.0` 固定清单仍有十五项：原有十项能力，加 `market_trading_session` 与 `major_broad_indices` 两项新增可执行能力，合计十二项按 tier 和适用条件执行；`whole_market_turnover`、`whole_market_margin`、`market_wide_intraday` 三个槽位明确 unsupported，不产生对应 operation obligation、观测、计算、主张或 coverage。

`fast` 执行四项 core；`standard` 在 core 之外执行原有八项 standard 增强。deep 仍需显式请求，已退出的槽位返回稳定 unsupported 原因，不伪装成来源失败或会话外 skip。行业板块广度、单证券／指数成交额和任意两所合计均不能代理已退出的全市场量值。

旧 market overview `@1.0` 与筛选入口仍在任何来源／artifact I/O 前拒绝。其他原有工作流及现有单证券盘中／复盘能力保持原语义。筛选、排名、候选深研、公共结果包流程与全市场盘中仍按 C 退出，不重新引入。

## 最终门禁

Python 3.12 完整测试、Ruff、strict mypy、Skill 校验、clean/copy install、文档／分发／敏感路径检查与独立 Standards／Spec 审查均保留。所有有效票、依赖消费、绑定定义及必要证据须一致，集成点与指定远端分支精确回读相等后才能判定完成。
