# v0.2.0 发布审计（2026-08-03）

本文记录 A 股研究技能 v0.2.0 的发布门禁和发布后回读。v0.2.0 在稳定的 `ResearchTask` Interface 上新增 `intraday_market_signal` 研究级盘中行情快照；它不增加盘中专用顶层命令，不改变 `schema_version: "1.0"`，也不把实验来源 operation 描述为已经完成生产准入。

## 候选范围

- 公共调用仍只有 `skill/a-share-research/scripts/entrypoint.py run --request <research-task.json>`；
- 请求只接受当前北京时间交易日的一只规范 SSE/SZSE A 股，`window` 为 `null` 且必须允许实验来源；
- 通达信同一观测提供快照基准，腾讯是必须成功的独立核心价格交叉观测，不是 fallback；
- 结果保留证券身份、交易日、会话、价格类型、来源时点、单位、字段血缘、冲突、错误和限制；
- 两个 operation 仍为实验来源，正常快照和双源确认停牌最高为 `limited`，来源不足或核心冲突时 `blocked`；
- `mootdx==0.11.7` 仅是 F10 与盘中能力范围内锁定的可选依赖，缺失时不会扩大阻断范围；
- README 中英文版安装目标固定为 `v0.2.0`，案例只保存请求契约，不保存或伪造来源成功响应。

## 显式 live probe

维护者入口为：

```text
<python> tests/live_probe_intraday.py --confirm-live --as-of YYYY-MM-DD
```

它覆盖一只 SSE 与一只 SZSE A 股，使用临时 home，输出脱敏诊断，不写夹具、来源响应、缓存、凭据或项目全局配置，也不进入普通 CI。2026-08-03 盘后显式运行时，两只证券均在成功加载 `mootdx==0.11.7` 后返回结构化 `blocked / intraday_session_not_applicable`；这证明依赖与会话门禁按契约工作，不证明盘中来源已通过生产准入。
