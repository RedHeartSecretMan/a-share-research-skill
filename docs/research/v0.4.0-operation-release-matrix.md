## 分母与闭合

当前公开计划包含 46 个 producer owner、61 个规范化 capability／producer 应用。E 明确豁免的两项 `intraday_market_snapshot` 应用保留同候选安装与离线证明，结论为 `not_live_verified_this_release`，没有被计为来源尝试、失败或成功。本次必须联网验证的 44 个 owner、59 个应用全部有真实公开执行状态 `succeeded` 或 `failed`；同 owner 在别的 capability 执行不能代替本应用。

28 个预先列明的请求场景形成有效公开计划，其中包括独立的 SZSE 趋势和单证券估值场景。实际执行 29 次公共进程，含一次 SZSE 趋势请求键设置错误的 I/O 前拒绝；修正后另计 1 次恢复。原失败保留为 exit 2、source attempt 为 false，不进入有效来源尝试。正式操作资格和默认安装加载均为 46/46；本次实际请求字段去向为 701/701。真实 health 中有 3 条公开 operation 安装状态记录；45 个匿名公开计划 owner 和单独可选 IWC 的计划／加载事实属于另一视角，不能相加扩大分母，也不能据此推断依赖未安装。内部 baostock／pypdf 依赖归属单独保留。

最终逐 owner 来源结果保留为：`complete` 15、`credential_blocked` 1、`observed_empty` 1、`partial` 2、`unavailable` 25。`attempted` 仅代表执行事实；`unavailable` 不表示全局不存在合格来源，`credential_blocked` 不表示已读取用户凭据，安装成功也不证明数据可用。两项新增能力的语义可用性另由三所会话／固定四指数实际 E2E 支持。

## 三份证据

- [当前资格](v0.4.0-overview-v2-operation-qualification.json) 绑定公开来源用途、时点、单位、失败、空集、凭据与限流契约。
- [最终证据](v0.4.0-release-probe-evidence.json) 由同候选、带时区、脱敏 typed attempts 派生，保留全部原始状态和独立 E 离线记录。
- [发布矩阵](v0.4.0-operation-release-matrix.json) 仅由资格和最终证据确定性生成，不手工修改字段、计数或摘要。

矩阵中的具体 applications 保留各请求／工作流位置，规范化 61 项清单按 capability／producer 去重，二者不能混用计数。生成器在当前策略下始终验证应用闭合，即使报告未实际使用豁免，也不能退回 producer 层覆盖。通用和历史 v0.3.0 契约保持原语义。

## 离线复验

从仓库根目录运行：

```text
<python> tests/generate_core_operation_release_matrix.py --check \
  --qualification docs/research/v0.4.0-overview-v2-operation-qualification.json \
  --release-evidence docs/research/v0.4.0-release-probe-evidence.json \
  --output docs/research/v0.4.0-operation-release-matrix.json
```

该命令不访问外部来源。重采集需要重新冻结实际安装内容，先记录具体适用画像、当前日期、完成日、独立预算、脱敏与停止条件；不得把旧候选证据重标为新候选，也不得为本版等待盘中交易窗口。
