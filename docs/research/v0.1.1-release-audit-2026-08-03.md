# v0.1.1 发布候选审计（2026-08-03）

本文记录 A 股研究技能 v0.1.1 的本地发布候选审计。v0.1.1 是基于已发布 v0.1.0 的兼容文档与 Agent 呈现修订，不改变公共 CLI、ResearchTask schema、计算方法或来源资格；因此不重复把 2026-08-02 至 2026-08-03 的真实来源 smoke 描述为新的现场观测。

## 候选范围

- README 中英文版固定安装目标为 `v0.1.1`，解释 Spec 0001–0004、F10、跨平台 Python 选择和 `mootdx` 的可选角色；
- `SKILL.md` 从 2366 个空白分隔词收敛到 726 个词，保留研究步骤、完成条件和核心守则，将任务分支与命令细节按需指向引用文档；
- `references/analysis-boundary.md` 成为研究判断、Agent 计算、条件触发位、外部署名观点和投资行动建议的唯一执行规范；
- `CONTEXT.md` 补充研究判断、研究建议、条件触发位、投资行动建议和 F10 资料等领域术语；
- 蓝色光标与工业富联案例补充 Agent 研究判断、主要风险、失效条件和可复算条件触发位；
- 历史 Spec 0003 保持 v0.1.0 基线，新增 Spec 0004 描述本次补丁范围；历史 v0.1.0 发布审计只补全已发生的远程门禁。

## 前向行为验证

使用四个不继承修复上下文的新 Agent 实例，仅提供安装产物和已执行 CLI 的结构化结果：

| 场景 | 结果 | 验收 |
| --- | --- | --- |
| 身份直答，整体 `limited` | 只确认 `SSE:600519`、日期、证据与发行人关系限制 | 没有附加估值、走势或投资判断 |
| 估值整体 `blocked` | 说明证券类别范围未建立，列出继续研究所需证据 | 没有生成估值压力判断或重新评估价格位 |
| 走势整体 `limited`，需要解释 | 给出有支持与反对证据的 Agent 推断、风险和可复算重估条件 | 首次运行把 Agent 补算混入“项目计算”标题，触发边界修订 |
| 修订后重新运行走势场景 | 将 CLI 返回指标标为项目计算，将新增简单推导明确标为 Agent 计算 | 研究判断、计算谱系、条件触发位和风险说明均符合边界 |

前向样本验证的是呈现分支和谱系标签，不把示例中的合成 locator 或固定数字当作真实市场事实。
