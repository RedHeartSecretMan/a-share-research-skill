## v0.3.0 交付范围

v0.3.0 通过唯一公共 `run --request` 入口交付 12 类版本化 ResearchTask、6 个固定研究方案和统一 14 字段结果信封。综合单标的与综合市场方案只编排既有窄任务；局部失败、空集、冲突、不支持能力和兄弟步骤结果都保留在同一结果中。

综合市场方案明确保留 5 个不支持能力：交易日与会话、主要宽基指数、全市场成交额、全市场融资融券和全市场盘中微观结构。这些能力没有 v0.3.0 正式来源操作，不生成伪造的观测、主张或计算；其后续路线属于 v0.4.0 范围。

## 发布边界

本审计随 `v0.3.0` 标签交付。发布动作必须把 `main` 与 annotated tag 原子推送到同一远端，随后回读确认远端标签解析到同一提交；GitHub Release 也必须绑定该标签。README 的安装命令固定使用 `--branch v0.3.0 --single-branch`，避免把后续移动的 `main` 当作不可变发布版本。

历史 v0.0.1–v0.2.0 版本均已发布并保留独立审计，见 [`history/`](history/)。这些历史现场结果不代表 v0.3.0 当前来源状态。
