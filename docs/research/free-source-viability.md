# 首版“当前估值证据简报”免费数据源可行性

状态：**未通过生产数据源准入门槛；不得据此开始实现生产 Adapter**

研究快照：2026-08-01（Asia/Shanghai）

适用规格：[首版规格：当前估值证据简报](../specs/0001-current-valuation-evidence-brief.md)

## 结论先行

在“SSE、SZSE 为首版市场，BSE 仅探测；无需购买订阅、积分或单独权限；Python 3.12+ 运行时只用标准库”的已确认约束下，**目前没有找到一条能完整支撑总市值、PE TTM、PB MRQ 的免费生产证据链**。

主要阻断不是 HTTP 连接，而是四个更深的契约问题：

1. 上交所、深交所公开网页背后的行情 JSON 可以无凭据读取，也能由标准库解析，但它们是页面内部接口，没有独立发布的稳定 API/schema 契约；“未复权”语义没有在这些网页接口上得到正式说明。深交所网页响应中的交易阶段值 `00` 也不能与交易所正式 STEP 规范直接对应。
2. 免费公开股本数据不能可靠提供“研究时点已经生效、精确到股的普通股总股本”。上交所同一官方域名下的两套不透明查询对同一证券给出不同数据日期或空结果；深交所股票列表只给到 `0.01 亿股`，分辨率为 100 万股。
3. 法定定期报告可以免费定位和下载，但报告原件是 PDF。Python 3.12 标准库可下载和校验 PDF 字节，不能可靠抽取其中的表格、合并口径归母净利润和归母净资产。未找到可替代 PDF、同时覆盖一季报/半年报/三季报/年报的当前免费正式结构化接口。
4. 交易所、巨潮和 Tushare 的条款均对商业使用、传播或再分发作出限制；北交所更明确要求行情使用许可并收费。开源代码本身不等于获得下游使用和证据再分发许可。

因此，当前原型的门槛结论是 **NO-GO**。公开网页接口仍有价值，但只能保留为实验、发现、诊断或交叉核验候选，不能单独使事实主张达到“已支撑”。

## 证据状态和通过门槛

本文使用以下标识：

- **[已验证]**：由数据所有者/法定披露平台的正式文档、条款或 2026-08-01 的一手响应直接支持。
- **[未验证]**：缺少凭据、权限、稳定文档、代表性失败样本或当前可访问实例，不能作肯定判断。
- **[推断]**：由多个一手事实推导出的工程判断，不冒充来源直接声明。

一个能力只有同时满足以下条件才算“通过”：

1. 字段能路由到唯一交易所和证券，且证券状态不靠猜测。
2. 值、单位、复权口径、交易状态、证据时点和公开时点语义均已验证。
3. 能以研究时点为边界，拒绝陈旧、未来、错证券、错口径、空响应和部分响应。
4. 至少完成 SSE 主板、SSE 科创板、SZSE 主板、SZSE 创业板代表样本及关键失败案例校准。
5. 正常路径无需购买订阅、积分或单独权限；免费注册凭据可以接受。
6. Python 3.12 标准库足以完成生产解析。
7. 来源条款允许项目所需的自动访问、最小事实输出和测试证据使用。

只要精确有效股本、共同估值价格、定期报告公开边界或财务分母中任一项不通过，三项估值就不能整体进入生产实现。

### Tushare 为什么不算本规格的免费注册基线

**[已验证]** Tushare 提供语言无关的 HTTP POST JSON API，响应有 `code/msg/data.fields/data.items`，因此技术上可用 `urllib.request` 和 `json`，不必安装其 Python SDK；无权限时正式返回码包括 `2002`。参见 [Tushare HTTP API 说明](https://tushare.pro/document/1?doc_id=130)。

**[已验证]** 当前官方文档中，[交易日历](https://tushare.pro/document/2?doc_id=26)、[利润表](https://tushare.pro/document/2?doc_id=33)和[资产负债表](https://tushare.pro/document/2?doc_id=36)均要求至少 2000 积分；利润表给出 `n_income_attr_p`，资产负债表给出 `total_hldr_eqy_exc_min_int`，字段语义正好满足估值财务分母。可是[积分规则](https://tushare.pro/document/1?doc_id=13)显示新注册仅得 100 分，2000 分通常需要长期社区贡献、特定高校身份或付费取得，且权限通常一年有效。每日精确股本接口 `stk_premarket` 虽声明“与积分无关”，仍要求另行在线开通，未登录无法确认是否免费，参见[每日股本（盘前）](https://tushare.pro/document/2?doc_id=329)。

**[已验证]** [Tushare 数据服务协议](https://tushare.pro/document/1?doc_id=405)将服务许可限定为个人、不可转让、非商业、可撤销且有期限，并禁止以营利/经营目的开通相关服务。故即使某位维护者通过贡献免费积累到 2000 分，也不能据此证明任意 Skill 用户都有无需购买权限、且适合开源通用分发的基线。

### 2. 交易日历与最近完成交易日

**[已验证]** 上交所现行[交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)规定交易日通常为周一至周五，法定节假日和交易所公告休市日除外；上交所有[年度休市安排栏目](https://www.sse.com.cn/disclosure/dealinstruc/closed/)。深交所发布了[2026 年节假日休市通知](https://www.szse.cn/disclosure/notice/t20251222_618087.html)，北交所也发布了[2026 年休市安排](https://www.bse.cn/important_news/200027428.html)。

**结论：有条件通过静态日历，机器契约和异常日仍未通过。**

### 4. 研究时点有效总股本

这是当前最明确的生产阻断项。

#### SSE 的陈旧、空结果和不透明替代查询

**[已验证]** 上交所[股本结构页面](https://www.sse.com.cn/assortment/stock/list/info/capital/index.shtml?COMPANY_CODE=600519)当前脚本使用 `COMMON_SSE_CP_GPLB_GPGK_GBJG_C`，页面标签为“发行总股本（万股）”并带 `REAL_DATE`。实际响应：

- [600519 页面查询](https://query.sse.com.cn/commonQuery.do?isPagination=false&sqlId=COMMON_SSE_CP_GPLB_GPGK_GBJG_C&companyCode=600519)：`REAL_DATE=2022-03-25`，`DOMESTIC_SHARES=125619.78`。
- 相同查询对 `688326` 返回空结果。

**[已验证]** 另一个同属上交所域名、但未见于当前页面脚本的查询 [`COMMON_SSE_CP_GPJCTPZ_GPLB_GPGK_GBJG_C`](https://query.sse.com.cn/commonQuery.do?isPagination=false&sqlId=COMMON_SSE_CP_GPJCTPZ_GPLB_GPGK_GBJG_C&COMPANY_CODE=600519)，在同日给出 `600519 TOTAL_DOMESTIC_VOL=125008.16, TRADE_DATE=20260731`，对 `688326` 给出 `11993.23` 万股。两个查询的数据日期、覆盖和结果明显不同，而后者没有公开字段契约。

**[已验证]** 发行人事件公告能给出精确到股和生效安排。例如经纬恒润[限制性股票回购注销公告](https://big5.sse.com.cn/site/cht/www.sse.com.cn/disclosure/listedinfo/announcement/c/new/2026-02-25/688326_20260225_1HJU.pdf)给出拟于 2026-02-27 完成注销，并列示注销后 119,940,960 股；公告也提醒最终以登记结算公司的股本结构表为准。这说明“报告期末股本”或四舍五入的网页快照都不能替代逐事件的生效校验。

#### SZSE 的精度不足

**[已验证]** 深交所 A 股列表把 `agzgb` 明确标为“亿股”。SZSE:000001 的一手值为 `194.05` 亿股，最小显示单位 `0.01 亿股` 等于 100 万股。用它计算总市值会把舍入误差直接放大到价格乘数，且列表只有 `2026-07-31` 页面日期，没有事件级生效依据。

#### 可替代候选仍不合格

**[已验证]** Tushare `stk_premarket` 的 `total_share` 以万股表示并显示 4 位小数，理论上可精确到股且有交易日；但需单独开通权限、成本未验证，服务条款又限制个人非商业使用，不能进入本项目免费通用基线。

**[推断]** 从法定 PDF 中维护“股本事件账本”可以形成研究时点值，但需要可靠 PDF/XBRL 解析、事件类型覆盖、登记结算最终结果校验和修订处理；这已经超出当前标准库约束。

**结论：阻断。** SSE、SZSE 都没有找到免费、正式、精确、时点有效且标准库可直接解析的总股本操作。

### 6. 归母净利润和归母净资产

#### 上交所结构化业绩概览覆盖不足

**[已验证]** 上交所[上市公司经营业绩概览](https://www.sse.com.cn/disclosure/listedinfo/listedcompanies/)说明数据来自公司报送 XBRL，且仅供参考、以 PDF 为准。页面内部响应：

- [600519 业绩概览 JSON](https://query.sse.com.cn/commonSoaQuery.do?isPagination=false&sqlId=COMMON_SSE_PL_XBRL_YJGL_XQ&reportYear=2026%2C2025%2C2024&stockId=600519)
- 字段映射脚本：[`search_listed_companies.js`](https://www.sse.com.cn/xhtml/home/2021public/querySearch/search_listed_companies.js)

2025 年报行中 `S2090_0040=8,232,006.71` 万元，页面脚本将其显示为归属于普通股股东的净利润；但当前响应只覆盖年报和半年报行，没有 2026 一季报和 2025 一季报，无法形成 `上一年全年 + 本年累计 - 上年同期累计`。`S2010_0380` 和 `S2010_0690` 分别与总资产、总负债及资产负债率相符，不是“归属于母公司股东权益”。

**[未验证]** 上交所介绍了 [XBRL](https://www.sse.com.cn/services/information/xbrl/ssexbrl/index.shtml) 和分类标准，但本次没有发现当前可公开、稳定下载全部报告实例文档的 URL 契约；历史 XBRL Online 主机当前也未形成可验证的实例下载路径。

#### 深交所/巨潮结构化财务旧接口当前不可用

**[已验证]** 巨潮公司详情页当前官方脚本 [`company-detail-cn.js`](https://static.cninfo.com.cn/new/js/app/company-snapshot/company-detail-cn.js?v=20260710082532)仍引用 `/data/yellowpages/singleStockData?...&mergerMark=financeData`。2026-08-01 对 HTTP、HTTPS 及带浏览器请求头/来源页的实际请求均返回 HTTP 200、零长度正文。这是必须显式识别的“成功状态码 + 空证据”失败模式。

**[未验证]** 深证信数据服务平台 [`webapi.cninfo.com.cn`](https://webapi.cninfo.com.cn/)有注册、token、API 文档、商城和权限机制；未登录状态下无法证明满足本任务字段的 API 是否免费。实际前端存在“免费 API”和“需购买 API/升级 VIP”的两类流程，故不能把平台注册本身等同于相关接口免费可用，也不能索取或猜测凭据。

#### PDF 原件是权威但标准库不能可靠取数

**[已验证]** 贵州茅台 2026 一季报、2025 年报和 2025 一季报原件已经能免费定位、下载并以字节哈希留证。它们包含计算 TTM 归母净利润和 MRQ 归母净资产所需的法定合并口径字段。

**[已验证]** Python 3.12 标准库没有 PDF 文本/表格解析器。`urllib.request`、`hashlib` 和 `pathlib` 只能完成下载、校验和保存；不能稳健处理 PDF 字体映射、对象流、扫描页、跨页表格和位置语义。用正则搜索 PDF 原始字节不是合格解析。

**结论：阻断。** 当前免费结构化接口覆盖不足或不可用，权威 PDF 又无法由标准库可靠解析。

### 7. Python 3.12 标准库充分性

**[已验证]** 本次用 `urllib.request`、`urllib.parse` 和 `json` 成功访问并解析了 SSE 日线/快照/身份/股本/业绩概览、SZSE 股票列表/日线/快照、巨潮证券字典和公告检索。所使用 API 均存在于 Python 3.12。`decimal.Decimal`、`datetime`、`zoneinfo`、`hashlib`、`xml.etree.ElementTree` 也足以承担十进制计算、北京时间、证据哈希和 XML/XBRL 解析。

**[未验证]** 当前机器没有 `python3.12` 可执行文件，实时短程序实际运行于 Python 3.14.6；因此本次没有完成最低版本的真实解释器验证。更高版本通过不能代替后续 CI 的 Python 3.12 验证。

**[已验证]** 即使网络和 JSON 部分完全兼容 3.12，标准库仍不包含可靠 PDF 解析能力；HTML/CMS 和手工解包 XLSX 的标准库方案也没有稳定 schema，不能把“能写解析代码”当成“语义契约已通过”。

**结论：标准库足以访问和解析合格 JSON/XML；不足以完成当前唯一可得的权威 PDF 财务链，因此对完整首版不充分。**

**[已验证]** [巨潮页面声明](https://www.cninfo.com.cn/new/snapshot/companyDetailCn?code=600519)同样把公开内容免费使用限定在非商业浏览/下载，并限制以直接或间接出售牟利为目的的复制、抓取、传播和再分发。

**[已验证]** 北交所[境内行情授权指南](https://www.bse.cn/application/guide.html)说明其行情由中证股转科技独家管理，任何使用行情信息的机构均须申请，未经许可不得发布、使用和传播，Level-1 使用按业务分类收费；北交所现行[交易规则](https://www.bse.cn/jygl_list/200028217.html)也规定交易信息归北交所所有。

**[推断]** 开源发布 Adapter 代码、让用户自行访问和在本机生成少量事实，与打包/镜像/出售交易所原始数据并不相同；但当前条款没有明确授予“自动化通用 Skill + 可能商业下游 + 响应夹具再分发”的权利。生产准入前至少需要数据所有者对自动访问、衍生指标输出、最小测试夹具和商业下游的书面澄清。未澄清前，不应提交完整原始响应或报告 PDF 作为公开仓库夹具。

**结论：SSE/SZSE/CNINFO 需书面澄清；BSE 行情明确不属于免费基线。**

## 已观察到的失败模式

| 失败模式 | 一手证据 | 生产要求 |
| --- | --- | --- |
| HTTP 200 但正文为空 | 巨潮 `singleStockData` | 空正文必须是结构化上游错误，不能当“公司无数据” |
| 同一官方域名查询的新旧数据冲突 | SSE 600519 股本：2022-03-25 与 2026-07-31 两套结果 | 要求有效日期、来源版本和独立事件校准；冲突即不可计算 |
| 官方列表值被显示精度截断/舍入 | SZSE 总股本只到 `0.01 亿股` | schema 必须定义分辨率；不允许伪造精确值 |
| 网页字段名与正式技术规范无法映射 | SZSE `tradingPhaseCode1/2=00` | 状态未知时 fail closed，不凭名字猜枚举 |
| 不透明查询标识和前端接口漂移 | SSE `sqlId`、SZSE 页面 API、CNINFO POST | 固定响应 schema、canary、内容类型和必填字段校验 |
| 日线空结果语义不明 | 可能是停牌、退市、未上市、错路由、限流或故障 | 必须结合身份、交易日历、交易状态和错误响应分类 |
| 公告时间只有日期 | CNINFO `announcementTime` | 同日研究保守处理并记录实际获取时间 |
| 权威内容只在 PDF | 定期报告、股本事件公告 | 没有合格解析器就返回“不可计算”，不得正则猜值 |
| 凭据存在但接口权限不足 | Tushare `2002`；深证信平台有购买/VIP 流程 | 不索取、不打印、不猜测凭据；返回明确权限阻断 |
| 网站访问策略/网络差异 | BSE 对非浏览器请求可返回 403；SSE 行情使用 32042 端口 | 超时、403、TLS、代理、反爬分别归类，不静默切换来源 |

## 最终门槛判定

### 必须同时成立的通过条件

在开始生产 Adapter 前，至少要以 SSE:600519、SSE:688326、SZSE:000001、SZSE:300750 和一个停牌/退市/公司行动失败样本证明：

1. 规范证券身份唯一且当前状态明确。
2. 最近完成交易日由交易日历和正式日线共同确认。
3. 收盘价被正式或经公司行动样本校准为未复权，并有可解释交易状态。
4. 总股本精确到股、含限售股、在研究时点已经生效，且多类别/多市场发行人被阻断。
5. 每一份财报在研究时点已经公开，合并报表版本、单位和更正状态明确。
6. TTM 三段归母净利润和 MRQ 归母净资产均能从权威、机器可解析来源取得。
7. Python 3.12 实际 CI 通过，正常运行不依赖第三方包。
8. 空值、限流、权限、反爬、协议漂移和来源冲突均 fail closed。
9. 条款允许项目的自动访问、最小事实输出和必要测试证据使用。

### 当前结果

- 条件 1、2：仅有条件满足。
- 条件 3：SSE 部分满足；SZSE 状态与两市未复权语义未满足。
- 条件 4：两市均未满足。
- 条件 5：日期级部分满足，日内和版本处理未满足。
- 条件 6：未满足。
- 条件 7：JSON 路径部分满足，PDF 路径与 Python 3.12 实机未满足。
- 条件 8：已识别失败模式，但尚无生产契约测试。
- 条件 9：未满足；BSE 明确需要许可，其他来源需澄清。

**最终结论：NO-GO。** 当前免费组合不能通过首版数据源准入门槛。按现有规格，生产 Adapter、估值计算和公开响应夹具都应继续暂停。

## 可行的下一步（不代表已改变项目约束）

1. 向 SSE、SZSE/深圳证券信息有限公司分别书面确认：公开网页自动访问、派生估值的最小事实输出、开源 Adapter、脱敏最小响应夹具以及商业下游是否获准；同时询问是否有正式免费 EOD、精确总股本和 XBRL/JSON 定期报告接口。
