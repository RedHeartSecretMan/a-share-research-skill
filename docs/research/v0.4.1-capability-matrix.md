## 状态解释

- `retain` 不改变用户可见语义，允许内部整理和测试 profile 化；
- `refactor` 保留产品意图，但必须完成该行的独立验收才能提升为公开支持；
- `defer` 保留范围记录，不产生来源执行、coverage、观测或公共主张。

市场筛选的 `defer` 状态表示：v0.4.1 将其作为不支持功能处理。当前运行时继续在来源或 artifact I/O 前拒绝；代码、夹具和历史证据不构成公共支持。
