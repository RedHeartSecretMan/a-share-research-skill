# v0.1.0 发布审计（2026-08-03）

本文记录完整 A 股研究技能 v0.1.0 的发布候选审计。它是带时间边界的验收记录，不保证外部免费接口在未来仍可访问或返回相同结果，也不把实验来源的观测描述为已独立核验事实。

## 当前结论

23 个能力矩阵场景都有确定性任务契约、离线契约测试和真实联网 smoke，四套流程均完成真实生产入口 smoke。主题研报在显式移除 iWencai 凭据变量后，通过东财全市场研报流的标题关键词基线取得 9 份材料；它明确保持为非语义、非完整主题宇宙的 `limited` 结果，iWencai 只作为可选增强。

降级复核发现并修正了三个聚合状态缺口：自动估值关键输入缺失、明确请求的任一内容类型缺失、资本事件任一类型为 `indeterminate` 时，现在都整体 `blocked` 并保留已取得的部分结果。最终发布仍以本文末尾的全量验证、远程 tag 干净安装和 GitHub Release 状态为准。

## 环境与方法

- 研究日期：`2026-08-03`，`Asia/Shanghai`；冻结案例与既有市场信号/ETF 期权记录锚定 `2026-08-02`。
- 宿主机：Darwin arm64；主要运行时：Python 3.12.8。
- 代码基线：`b88061f` 加 Issue #21 尚未提交的发布审计与 Demo 文档变更。
- 公共入口：`skill/a-share-research/scripts/entrypoint.py run --request <temporary-request> --output <temporary-result>`。
- 当前快照类示例只在 `/private/tmp/a-share-research-v0.1.0-smoke` 生成临时副本并改为实际研究日期；仓库里的冻结请求没有被现场运行改写。
- 每次 smoke 检查退出码、空 stderr、单一 JSON、公共字段、任务特定结构、来源操作或来源调用后错误，并对 stdout 计算 SHA-256。
- `limited` / `blocked` 只有在存在来源观测、locator，或 `upstream_unavailable`、`unknown_schema`、`empty_response`、`quote_time_conflict` 等来源调用后错误时，才计为真实触源。
- `missing_credential`、`missing_optional_dependency`、策略门禁、无效请求和当前北向披露前置门禁不计为真实触源。
- 动态原始 JSON 只保留在本机临时目录；仓库记录稳定状态、错误码、计数和哈希，不提交供应商大段原始载荷。

F10 smoke 在临时 `uv` 环境中精确安装 `mootdx==0.11.7`；版本来自 [PyPI 的 mootdx 0.11.7 发布页](https://pypi.org/project/mootdx/0.11.7/)，没有写入核心运行时依赖。首次运行由该依赖自动生成了 `~/.mootdx/config.json`；本次审计未读取、提交或擅自删除该文件。

## 降级资格

本项目按 Adapter operation 而不是供应商品牌判断资格。当前 [Adapter 准入矩阵](adapter-qualification-matrix.md)没有任何 operation 完成生产准入，因此实验交叉观测不自动等于合格独立 fallback。快讯实现了 CLS → 东财的实验接管链，但两端仍是实验来源；走势和 ETF 中代码名为 fallback 的第二来源是必需交叉核验方，不能接管主来源。

| 能力组 | 合格独立 fallback | 失败关闭契约 |
| --- | --- | --- |
| 自动估值 | 无 | 价格、股本、财务或一致预期任一关键输入不可用时，单票整体 `blocked`，已取得证据和不可计算指标仍保留 |
| 批量估值 | 无 | 每行复用单票契约；阻断行不删除，部分阻断时整体 `limited` 并披露阻断行，全部阻断时整体 `blocked` |
| 个股走势 / ETF 行情 | 无 | 主来源与强制交叉源任一失败、缺日或冲突时整体 `blocked` |
| 研报 / F10 / 新闻公告 / 互动易 | 无 | 每个明确请求的 material type 都必须有材料；任一类型缺失时整体 `blocked`，同时保留其他类型材料和来源诊断 |
| 市场快讯 | 无；有实验接管链 | CLS 无材料时才允许实验东财接管；两端均不可用时 `blocked`，接管成功仍最高 `limited` 并记录 `fallback_used` |
| 北向 / 资金流 / 龙虎榜 / 解禁 / 两融 / 大宗 / 股东 / 分红 | 无 | 每个请求 data type 独立输出四态 coverage；任一类型 `indeterminate` 时整体 `blocked`。只有契约完整且无错误的空批次可成为 `observed_empty` |
| 市场信号 | 无 | 来源、schema 或覆盖不可判定时保留 `indeterminate`；没有把失败转换为零池，结果按请求所需基础池失败关闭 |
| ETF 期权 | 无 | 合约、标的或报价时点冲突时整体 `blocked`；不回退到其他 ETF，也不拼接跨时点报价 |

这项登记满足“有合格降级，或明确没有合格降级并失败关闭”的发布门槛；`limited` 只表示已经建立了回答所需的关键实验观测但仍有资格或非关键限制，不表示来源已经通过生产准入。
