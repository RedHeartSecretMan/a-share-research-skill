# 蓝色光标：最近 10 个交易日走势研究

## 用户提示词

> 使用 `$a-share-research`，研究蓝色光标截至 2026-08-02 最近 10 个完整交易日的未复权走势。给出 OHLCV、累计涨跌、最大回撤、波动、涨跌天数和量能变化，并基于这些证据总结走势；不要给买卖建议。

## Skill 执行

```text
<python> <skill-root>/scripts/entrypoint.py run --request examples/requests/bluefocus-10-day-trend.json
```

Agent 把自然语言问题转换为版本化任务；CLI 先交叉解析证券身份，再取得深交所与腾讯两组未复权日线，并逐日核对证券、交易日、OHLCV 和复权口径。任何一日缺失或冲突都会阻断整段走势指标。

整体状态为 `limited`，不是 `supported`：证券身份由深交所与巨潮观测交叉；10 日日线由深交所与腾讯的未复权序列逐日一致确认，但这些免费联网操作尚未完成操作级来源资格审查。巨潮返回的 opaque `orgId` 也不足以独立确认发行主体关系，所以发行主体仍标为 `unverified`。

这是一份带证据边界的历史走势描述，不是评级、目标价、买卖建议或未来价格预测。
