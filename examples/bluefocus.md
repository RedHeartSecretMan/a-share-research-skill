# 蓝色光标：走势、交易信号与披露的交叉研究

## 用户提示词

> 使用 `$a-share-research`，研究蓝色光标截至 2026-08-02 最近 10 个完整交易日的未复权走势，并用 2026-08-03 的生产 smoke 交叉检查龙虎榜、未来解禁和公告新闻，同时参考 2026-08-02 的真实板块归属 smoke。明确不同证据的日期、状态和缺口，不要把共时性写成因果；在证据之后给出标为 Agent 推断的研究判断、主要风险和可复算的条件触发位，不要把触发位写成买卖指令。

## Skill 执行

这不是一个把不同来源直接拼成因果结论的单次请求。Agent 分别运行以下版本化研究任务，再按规范证券标识和时间窗口交叉解释：

```text
<python> <skill-root>/scripts/entrypoint.py run --request examples/requests/bluefocus-10-day-trend.json
<python> <skill-root>/scripts/entrypoint.py run --request examples/requests/bluefocus-dragon-tiger.json
<python> <skill-root>/scripts/entrypoint.py run --request examples/requests/bluefocus-lockup-90-day.json
<python> <skill-root>/scripts/entrypoint.py run --request examples/requests/bluefocus-board-membership.json
<python> <skill-root>/scripts/entrypoint.py run --request examples/requests/bluefocus-announcements-news.json
```

走势任务先交叉解析身份，再核对深交所与腾讯的未复权日线。交付 smoke 从相应示例请求生成临时请求：龙虎榜、解禁和公告新闻的研究日期锚定北京时间 `2026-08-03`；公告新闻的发布窗口仍截止 `2026-08-02`；板块归属沿用北京时间 `2026-08-02` 的真实 `market_signals` smoke。任一来源失败、覆盖不完整或身份不一致都保留为独立缺口，不能解释成“没有记录”。

## Agent 示例答复

蓝色光标被交叉核验为深交所 A 股 `SZSE:300058`。截至 `2026-08-02` 的固定现场记录中，最近 10 个完整交易日为 `2026-07-20` 至 `2026-07-31`：未复权收盘价从 `12.14` 上升到 `14.35 CNY/share`，累计涨幅 `18.2043%`；最大回撤 `-10.9611%`，年化波动率 `121.3998%`。9 个相邻交易日中有 5 日上涨、4 日下跌，后 5 日平均成交量比前 5 日增加 `30.7131%`。因此能够成立的走势描述是“高波动中的阶段性上涨，窗口末端价格和交易活跃度同时增强”，不能外推为未来仍会上涨。

### `2026-08-03` 生产 smoke 交叉证据

- 龙虎榜请求覆盖 `2026-07-01` 至 `2026-08-03`，生产 Adapter 真实触源后返回 `limited`，取得 1 条 `2026-07-31` 的可用龙虎榜观测，没有来源错误。该观测与固定走势记录的最后一个交易日相同，只能确认二者在日期上重合；龙虎榜原因、净买额和席位结构均不能证明当日上涨由某类资金推动。
- 未来 90 日解禁请求覆盖 `2026-08-03` 至 `2026-11-01`，真实触源后返回 `blocked`，来源错误为 `empty_response`，可用观测为 0。这个结果表示来源没有建立合同完整的解禁观测，不能改写成“未来 90 日无解禁”；仍需更换合格来源或稍后复核。
- 公告新闻请求以 `2026-08-03` 为研究日期，发布窗口为 `2026-07-01` 至 `2026-08-02`。真实生产结果为 `blocked`：它保留了 20 条 `stock_news`，但 `cninfo_announcement@1` 返回 `unknown_schema`、`szse_announcement@1` 返回 `pagination_incomplete`，明确请求的公告类型没有可用材料。新闻成功不再掩盖公告缺失；新闻也仅是署名材料，不能从标题推断业务事实或把发布时间与价格变化的接近解释成因果。

另有一份锚定 `2026-08-02` 的真实 `market_signals` 板块归属 smoke：结果为 `limited`，取得 20 条供应商板块观测，包括“传媒”“人工智能”“AI智能体”“广告营销”等标签，且没有来源错误。来源没有暴露分类类型，所以这些观测保持 `unclassified`；它们是供应商分类，不是公司基本面事实，也不是上涨原因。该板块现场比上述三项生产 smoke 早一个研究日，不能假定分类在 `2026-08-03` 仍完全相同。

## Agent 研究判断

以下内容是 Agent 基于上述固定证据形成的推断，不是来源事实，也不代表读取本文时的当前判断。研究周期是截至 `2026-08-02` 的最近 10 个完整交易日。

- **走势判断**：`2026-08-02` 的固定序列支持“高波动中的阶段性上涨，窗口末端出现价格与成交量同步增强”。但上涨主要集中在最后一个交易日，且 10 日最大回撤达到 `-10.9611%`、年化波动率达到 `121.3998%`，所以“趋势已经稳定”得不到这组证据支持。
- **交叉解释**：龙虎榜与上涨发生在同一交易日，只能形成共时性线索；板块标签、新闻标题、公告缺口和解禁缺口均不能证明上涨原因。现有证据更适合描述市场行为，而不足以建立基本面驱动论点。
- **主要风险**：单日价格贡献集中、波动率高、公告与解禁覆盖被阻断，以及板块标签分类语义不完整。任何一项都可能显著改变对这段走势持续性的解释。
- **条件触发位**：`12.66 CNY/share` 是 `2026-07-20` 至 `2026-07-30` 九个交易日的最高价。若从该研究时点向后出现连续两个完整交易日收盘低于 `12.66`，则“最后一日向上脱离前九日区间并具有延续性”的判断应被重新评估。该阈值使用未复权价格；若发生公司行动、复权口径变化或交易日序列不完整，必须废弃并重新计算。它不是买入点、卖出点、止损位或未来价格预测。
- **后续研究建议**：优先补齐公告原文、未来解禁的合格来源和龙虎榜完整席位口径，再核验板块标签的分类与生效时间；在这些缺口关闭前，不应把市场信号升级为基本面因果结论。

因此这份跨模块 Demo 的整体状态仍为 `limited`。Agent 可以给出上述有条件的研究判断，但不能据此生成评级、目标价、直接买卖或仓位指令。
